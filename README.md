# 📱 Projecte: Dues versions de l'aplicació

Aquest projecte conté dues versions de l'aplicació, desenvolupades en branques diferents de Git per mostrar dues implementacions del mateix projecte.

## 🌿 Branques del projecte

### 1. `master` · Versió original

Aquesta branca conté la versió base del projecte, amb la implementació original de l'aplicació.

<img width="254" height="184" alt="Captura de la versió master" src="https://github.com/user-attachments/assets/6e1655c8-ded1-4114-ba2d-7c4ddacec2c2" />

### 2. `iu` · Versió amb una interfície millorada 🎨

Aquesta branca conté una versió amb una interfície d'usuari (IU) més visual i atractiva, amb un disseny orientat a millorar l'experiència d'usuari.

<img width="189" height="407" alt="Captura de la versió IU millorada" src="https://github.com/user-attachments/assets/653c1e37-55a1-4e79-bc94-e2167286dd03" />

## 🔀 Com canviar de branca

Per consultar la versió original:

```bash
git switch master
```

Per consultar la versió amb la interfície millorada:

```bash
git switch iu
```

## 🎯 Objectiu

L'objectiu és mantenir dues versions del projecte per poder comparar la implementació original amb una proposta de millora de la interfície d'usuari.
